# Оганнисян Айк, сортировка Шелла и ключ вещественные числа (15 номер в списке)

## Как запустить

Нужно создать файл и в этом файле написать в таком формате данные таблица. Значение это строка

```
Ключ1 Значение1
Ключ2 Значение2
...
```

Вот пример входных данных

```
7.0 Про день Бородина!
3.0 Французу отдана?
12.0 Немногие вернулись с поля...
14.0 Не отдали б Москвы!
2.0 Москва, спаленная пожаром,
9.0 Не то, что нынешнее племя:
5.0 Да, говорят, еще какие!
11.0 Плохая им досталась доля:
15.0 Вот так-то, братцы, наши деды
1.0 Скажи-ка, дядя, ведь недаром
13.0 Не будь на то господня воля,
8.0 — Да, были люди в наше время,
4.0 Ведь были ж схватки боевые,
10.0 Богатыри — не вы!
6.0 Недаром помнит вся Россия
```

После нужно запустить программу передав файл через потоки в терминале (РЕКОМЕНДУЕТСЯ ЗАПУСКАТЬ ТОЛЬКО НА ЛИНУКС, САМ ЗАПУСКАЛ И ПИСАЛ НА DEBIAN 13)

```
./solve < test.txt
```

Дальше красиво все выдает и можно вести ключ, значение котрого бинарным поиском найдется
